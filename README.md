# Site M7 Automação

Site estático (HTML/CSS/JS) publicado na Vercel.

- Páginas geradas por `build.py` (`python3 build.py`). Edite o `build.py`, rode e faça commit dos `.html` gerados.
- `assets/app.js`: WhatsApp do Miguelzinho e webhook de leads (n8n → Supabase `site_lead_registrar`).
- Vercel: framework "Other", sem build command, output = raiz do repositório.
